# Components and assets

- Local `@nomos/svelte-ai-elements` 0.1.0 is an MIT adaptation of Sikandar Bhide's AI Elements, source revision `fa4bc217f84bc571378bc371332a154106772614`. LICENSE and UPSTREAM.md remain inside its archive. This consumer uses Message, PromptInput and Reasoning Root/Trigger, not the registry or provider recipes. Real reasoning uses a Bits UI Collapsible.Content with escaped text; its strings are never fabricated or normalized for history.
- Local `@nomos/svelte-magic` / `@nomos/svelte-fancy` 0.1.0 adapt Sikandar Bhide's MIT animations at `c0e5d02b35caf88bb09bd72a3e9c49031e1657ea`. Packaged notices are retained. Effects: BlurFade for the empty welcome; Letter3DSwap for the replay action; SparklesText for the model title; actual Dock/DockIcon for emotion-target controls. Reduced motion avoids mounting the type/title effects and disables Dock magnification. The title uses four small blue/pale-blue sparkles, supports click/keyboard pause and unmounts its effect while the browser tab is hidden. No shared-library files were changed.
- Bits UI 2.19.5 supplies the Dock's native-button Toggle and focus/hover Tooltip, alongside existing dialogs and tabs. Consumer-scoped Dock styling removes the showcase frame and inherited icon padding, uses 60px targets to accommodate the seven labels, and uses the existing blue/neutral tokens. Narrow/touch screens use a static Dock, with two rows on small phones. Recreating the Dock on motion-preference changes prevents an already-running spring from animating under reduced motion; target state lives outside that subtree.
- AI Elements was packaged from an isolated scratch copy because the shared source checkout had no package-build environment/dist. The original library source was not changed or bootstrapped in place. The consuming app compiles against the packed dist artifact.
- Geist Variable and Geist Mono Variable 5.3.0 use Fontsource's local font assets and bundled licenses. Browsing never loads Google Fonts/CDN font URLs.
- Icons are Phosphor Svelte 3.0.1. Supplied children replace AI Elements' default submit icon to keep the app's icon voice consistent.
- Native, code-rendered concept diagrams and score bars reflect the supplied fixture/record data. The connecting diagram strokes do not represent measured causal edges. No scientific image, car photo, generated person or stock avatar is used.
- The chat watermark is a transparent, image-tool-derived cutout of Adam's supplied `/home/adam/Downloads/muse.png`. It is decorative only, not a model-state indicator. Original, edited PNG and prompt are recorded in `docs/assets/`; the browser serves a local WebP. This is a supplied brand asset, not an original Nomos mascot; no redistribution/license or Meta endorsement is claimed.

Muse/Meta styling is inspiration requested by Adam. The app is an independent Nomos prototype, not official Meta UI or endorsed tooling. No remote registry JSON, generated component schemas or browser custom elements are used.
